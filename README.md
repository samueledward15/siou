# ⲤⲒⲞⲨ · سيو

تطبيق ويب لشباب سراج (١٥–٣٠ سنة): قراءات اليوم بالتقويم القبطي، وآية اليوم والحفظ على ٤ مراحل، والسما، والأجبية، و«حاسس بإيه؟».

- `index.html` و`app.js`: التطبيق (صفحة واحدة، بيتثبّت على الموبايل ويشتغل من غير إنترنت عن طريق `sw.js`).
- `engine.js`: نسخة المتصفح من محرك التقويم والقطمارس.
- `engine/`: مصدر المحرك وبيانات القطمارس واختباراته (`cd engine && node --test`).
- البيانات (النجوم والنتايج) بتتحفظ على جهاز المستخدم بس.

الشواهد من قطمارس موقع الأنبا تكلا بعد مراجعة خادم. الصور من فن قبطي قديم ملكية عامة (المتروبوليتان، كليفلاند، ويكيميديا)، ومصادرها جوه التطبيق في «عن الصورة».
